# InvestMatch website

The public site for InvestMatch, served by GitHub Pages at
https://roxanerasolo.github.io

- `index.html`: home page
- `support.html`: help and contact (App Store Support URL)
- `privacy.html`: privacy policy (App Store Privacy Policy URL, and the app's paywall)
- `terms.html`: terms of use (linked from the App Store description and the paywall)
- `data-sources.html`: where the market data comes from
- `404.html`: shown for any page that does not exist

Plain HTML, no build step. `.nojekyll` tells GitHub Pages to serve the files as they are.
